Stage Ingénieur Machine Learning & Data
Renault Group : Maintenance prédictive sur ligne de production

Sur une ligne de production industrielle, les capteurs génèrent en continu des données vibratoires denses et bruitées, il est difficiles à interpréter telles quelles. Mon rôle est de rendre ces données exploitables : je les nettoie, les filtre et les structure avant de les faire passer dans un modèle d'IA (un autoencodeur), qui fonctionne comme un rouage au sein d'une chaîne qui tourne en continu. Le modèle compare ce qu'il observe à un comportement "normal" appris, et transforme l'écart en décision : nominal ou anomalie. Cette décision remonte instantanément dans une interface web pour que les opérateurs voient le résultat en temps réel et puissent agir avant qu'une panne ne survienne.

  • Comparaison des approches de réduction dimensionnelle (PCA, KPCA, autoencodeur) — choix de l'autoencodeur neuronal pour la détection d'anomalies, anticipant les dérives d'équipements à partir de données vibratoires industrielles.
  • Pipeline Python optimisé pour le temps réel : temps de traitement ramené à 3,57 ms par cycle.
  • Interface web React / Next.js pour visualiser en direct les indicateurs de santé machine et aider les équipes opérationnelles à décider.

LERIA, Université d'Angers — Automatisation du montage vidéo par analyse audio/vidéo

Traditionnellement, faire coïncider les coupes d'une vidéo avec le rythme d'une bande son se fait au montage, à la main, image par image. Mon travail a été d'automatiser cette tâche : au lieu d'un montage manuel, un pipeline analyse conjointement le signal audio (tempo, énergie, transitoires) et le contenu vidéo, puis place lui-même les coupes aux bons instants pour produire un clip synchronisé.

  • Pipeline Python d'analyse audio et vidéo (librosa, OpenCV, moviepy) pour détecter automatiquement les points de montage rythmés par le son, sans intervention manuelle.
  • Tâche auparavant réalisée à la main, en plusieurs heures par clip, entièrement automatisée et ramenée à quelques secondes de traitement.
  • Pipeline testé et validé sur des jeux de données variés pour garantir la fiabilité de la synchronisation.
